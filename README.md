# Labstride.dev — Developer First concept

A responsive, dependency-free landing-page prototype for the Labstride open-source project, based on the public README and documentation at `https://github.com/engshort/labstride` (checked 2026-10-24).

## Preview

Open `index.html` directly in a modern browser. It includes HTML, inline CSS and a small amount of vanilla JavaScript for the mobile navigation and section tracking. No build steps or external libraries are required.

## Design direction

- Dark, technical UI with mint green accent and subtle architectural grid.
- No fake product screenshots or claims of a working install.
- Conceptual workflow visualization, explicit responsibility map, current project status, and open-source contribution routes.
- Responsive layouts for wide desktop, tablet and small mobile screens.
- Semantic sections, focus styles, reduced-motion support, mobile navigation, skip link, and accessible expandable FAQ.

## Sources & claims

Primary source: `README.md` in Labstride's public repository. Supporting pages: `docs/01-product-and-scope.md`, `docs/06-architecture.md`, `docs/14-work-packages.md`, `docs/adr/0006-hybrid-coordination.md`, `GOVERNANCE.md`, and `CONTRIBUTING.md`.

The site states that Labstride is not yet installable; source copy should be updated as releases and integrations progress. The diagrams are explicitly conceptual, not live system status.

## Deployment

The file can be served by any static hosting service. Replace `index.html` when updating; no application backend is necessary.
